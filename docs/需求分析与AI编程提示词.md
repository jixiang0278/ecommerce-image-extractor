# 需求分析与 AI 编程提示词

## 需求分析

目标用户在商品详情页批量收集商品图片，核心流程为「识别详情页 → 提取图片 → 新页筛选 → 转换 PNG → 下载并反馈」。

关键难点：

1. 三个平台及商家后台的 URL、DOM、懒加载字段不一致；需要分平台判断商品详情页，同时保留通用图片扫描策略。
2. 商品图可能来自平台 CDN；扩展页跨域获取原图时需要主机权限。未知 CDN 应在用户点击下载时按需请求权限。
3. `chrome.downloads.download` 返回下载 ID 只代表任务已创建；进度和完成反馈应监听 `chrome.downloads.onChanged`。
4. 实际原图尺寸可能要等加载后才能得知；除提取阶段过滤外，图库预览应二次过滤小图。
5. 商家版常用单页应用路由；按钮要跟随 URL 变化显示和移除。

验收标准：在支持的商品详情页显示悬浮按钮，其他页不显示；提取后的图库支持预览、尺寸、全选、反选及单张选择；选中的图片转换为 PNG 并逐张下载，最终显示成功与失败数量；扩展目录可直接在 Chrome 开发者模式加载；官网可在桌面和手机浏览，提供功能说明、安装步骤与扩展下载包。

## 可直接复制的 AI 编程提示词

```text
# 角色
你是一位资深 Chrome 扩展开发工程师，同时具备前端产品设计与自动化测试能力。你精通 Manifest V3、Content Script、Service Worker、chrome.storage、chrome.downloads、跨域图片获取、Canvas PNG 转换及响应式网页设计。你会交付可直接运行的项目，发现实现与需求不符时主动修改，直到通过可执行的验收检查。

# 任务
开发「电商图片提取器」Chrome 扩展，并制作一个用于展示和下载扩展的简洁官网。支持淘宝、天猫、京东和拼多多商家版商品详情页。核心流程：详情页右下角点击「获取图片」→ 新标签页集中展示 → 勾选 → 批量转换 PNG 下载。

# 扩展功能
1. 仅在上述平台的商品详情页显示右下角悬浮「获取图片」按钮；其他页面不显示。按钮圆角、有阴影、hover 和加载反馈，不明显遮挡原页面。
2. 提取商品相关图片，兼容 img/currentSrc/srcset、picture source、data-src、data-lazy-src、data-original 等懒加载属性以及 background-image。相对 URL 转绝对 URL、去重，过滤图标、logo、占位图、1×1 像素图和小于 100×100 的图片。处理平台差异和 SPA 路由变化。
3. 使用 chrome.runtime.sendMessage 将列表传给扩展；通过新标签页打开 gallery.html。图库使用响应式网格，显示缩略图、实际尺寸和复选框；提供全选、反选、已选数量与「下载选中图片」。无图、预览失败、权限被拒绝等状态要有明确反馈。
4. 下载时将选中原图统一转换为 PNG，按「商品图_001.png」命名，使用 chrome.downloads.download 保存到浏览器默认下载目录。逐张显示下载进度，监听 downloads.onChanged 确认完成或中断，结束后显示成功数、失败数及简短原因。单张失败不阻断其他下载。

# 技术约束
- Manifest V3；权限包含 activeTab、scripting、downloads、storage；host_permissions 覆盖 *.taobao.com、*.tmall.com、*.jd.com、*.pinduoduo.com、*.yangkeduo.com，并考虑常用图片 CDN。未知 CDN 使用 optional_host_permissions 按需请求。
- content_scripts 只匹配上述电商域名；代码模块职责清楚，关键逻辑有中文注释，无构建步骤、无伪代码，可在 chrome://extensions 直接加载。
- 处理跨域、登录态、图片解码、权限拒绝和下载中断。不要把大批量图片以查询参数传递；用 storage.session 传递结果。
- 不收集或上传用户数据；官网只作为展示和扩展下载入口。

# 官网
制作移动端友好的静态展示站，包含产品价值、核心功能、三步使用方法、支持平台、安装步骤和扩展压缩包下载按钮。不要编造用户评价、下载量或平台官方合作关系。官网源码独立于扩展目录。

# 测试与修复
完成后运行语法和 manifest 校验，使用模拟页面验证详情页识别、图片收集及过滤，再用可用的浏览器环境验证图库勾选、PNG 文件名、进度与完成反馈。记录实际测试范围；无法访问真实平台登录页时，明确说明未验证的范围。发现不满意的地方直接修改并重测。

# 交付格式
先说明文件结构与实现思路，再交付 manifest.json、content.js、content.css、background.js、gallery.html、gallery.js、gallery.css 的完整可运行代码，以及官网源码、测试结果和简短安装说明。不得省略关键文件或用伪代码代替。
```
